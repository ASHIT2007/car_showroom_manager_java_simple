# Mini Car Showroom Management System

A simple console-based **Car Showroom Management System** built in Java.  
Perfect for first-year engineering students to understand basic OOP concepts, ArrayList, Scanner, input validation, and menu-driven programs.

## Features

- Add a new car (model, color, year, price)
- View all cars in the showroom with nice formatting
- Search cars by model name (partial match, case-insensitive)
- Sell a car (changes status from "Available" to "Sold")
- Show count of currently available cars
- User-friendly menu with input validation
- Prevents invalid number inputs (year, price)

## Technologies Used

- **Language**: Java (JDK 8 or higher recommended)
- **No external libraries** — pure core Java
- **Data Structure**: `ArrayList<Car>`
- **Input Handling**: `Scanner` with robust validation

## How to Run

### Option 1: Using VS Code (Recommended for Beginners)

1. Open the project folder in VS Code  
   `File → Open Folder...` → select your project folder

2. Make sure you have installed:  
   - **Extension Pack for Java** (by Microsoft)

3. Open `CarShowroomSystem.java`
4. Click the **Run** button (green play ▶) above the `main` method  
   OR press **Ctrl + F5** (Run without debugging)

5. The program will start in the integrated terminal
